### 🛒 À propos

**Tana Electro Shop** est un site de boutique en ligne spécialisé dans les produits tech : nouveautés, accessoires et objets du quotidien.

Le visiteur peut parcourir le catalogue, rechercher un produit, enregistrer ses coups de cœur, remplir son panier et aller jusqu'à la validation d'une commande, **comme dans une vraie boutique**, mais sans aucun paiement réel.

> \[!NOTE]
> Ce projet est une \*\*vitrine de démonstration\*\*. Les produits, les prix et les avis sont fictifs, et aucune donnée personnelle n'est envoyée ni enregistrée sur un serveur.

### ✨ Fonctionnalités

||Fonctionnalité|Ce que ça apporte|
|-|-|-|
|🔍|**Recherche intelligente**|Trouvez un produit rapidement, y compris avec des mots accentués.|
|🗂️|**Filtres et tri**|Filtrez par catégorie et triez par nouveauté ou par prix.|
|❤️|**Favoris**|Gardez vos produits préférés de côté. Ils restent enregistrés dans votre navigateur.|
|🛍️|**Panier**|Ajoutez, retirez, modifiez les quantités. Le panier est conservé dans votre navigateur.|
|👀|**Fiche produit détaillée**|Aperçu complet du produit, quantité contrôlée et gestion du stock de démonstration.|
|🏷️|**Code promo et livraison offerte**|Essayez le code **`TANA10`**. La livraison devient gratuite à partir d'un certain montant.|
|🧾|**Récapitulatif de commande**|Vérifiez le détail de votre commande avant de la valider.|
|✅|**Commande simulée**|Un parcours d'achat complet, **sans paiement** et **sans transmission de données**.|
|📱|**Responsive**|L'interface s'adapte aux téléphones, tablettes et ordinateurs.|
|♿|**Accessible**|Navigation au clavier, états visibles et animations réduites si votre système le demande.|

### 🚀 Essayer la démo

Aucune installation nécessaire : ouvrez simplement le lien ci-dessous dans votre navigateur.

👉 [**tana-electroshop.vercel.app**](https://tana-electroshop.vercel.app/)

**Parcours conseillé en 1 minute :**

1. 🔍 Recherchez un produit ou filtrez par catégorie
2. ❤️ Ajoutez un article à vos favoris
3. 🛍️ Ajoutez deux ou trois produits au panier
4. 🏷️ Appliquez le code promo `TANA10`
5. ✅ Validez la commande (simulation, rien n'est débité)

### 💻 Installation

*Cette section s'adresse aux développeurs qui souhaitent lancer le projet sur leur machine.*

#### Prérequis

* [Node.js](https://nodejs.org/) (version LTS récente recommandée)
* npm (installé avec Node.js)
* [Git](https://git-scm.com/)

#### Étapes

```bash
# 1. Cloner le dépôt
git clone https://github.com/Steeve-cyber/tana-electroshop.git

# 2. Entrer dans le dossier du projet
cd tana-electroshop

# 3. Installer les dépendances
npm install

# 4. Lancer le serveur de développement
npm run dev
```

Ouvrez ensuite l'adresse affichée dans le terminal (généralement `http://localhost:5173`).

#### Commandes disponibles

|Commande|Description|
|-|-|
|`npm run dev`|Lance le site en mode développement avec rechargement automatique|
|`npm run build`|Génère la version optimisée pour la production|
|`npm run preview`|Prévisualise localement la version de production|
|`npm run lint`|Analyse le code avec ESLint|

### 💡 Bon à savoir

* 🧪 **Données de démonstration** : le catalogue, les prix et les avis sont fictifs.
* 💳 **Aucun paiement** : le passage de commande est une simulation et ne débite rien.
* 🔒 **Aucune donnée transmise** : vos favoris et votre panier restent uniquement dans votre navigateur.
* 🧹 **Réinitialisation** : vider les données du site dans votre navigateur remet les favoris et le panier à zéro.
