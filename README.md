# Tana Electro Shop

Vitrine e-commerce responsive pour une sélection de produits tech, réalisée avec React et Vite.

## Fonctionnalités

- Recherche avec prise en charge des accents, filtres par catégorie et tri par nouveauté ou par prix
- Favoris et panier conservés dans le navigateur
- Aperçu détaillé des produits, quantité contrôlée et gestion du stock de démonstration
- Code promotionnel TANA10, seuil de livraison offerte et récapitulatif de commande
- Parcours de commande simulé, sans paiement ni transmission de données
- Interface responsive, animations réduites selon les préférences système et états accessibles au clavier

## Démarrage

Installer les dépendances avec npm install, puis lancer npm run dev.

Le catalogue, les prix et les avis sont des données de démonstration. Le passage de commande ne déclenche aucun paiement.
